## Genuine finding and fix

The window boundary was not tested. The only window test gave the same result whether a strike
exactly `windowMs` old counted or not, and the approved spec (R10.5, T5.7) does not define
inclusivity. Fix in commit `fd15cfa`: ADR-0015 now states the rule (a strike counts while it is
less than `windowMs` old), `ban.ts` documents it, and a test pins `N-W-1` (outside), `N-W`
(outside) and `N-W+1` (inside). Mutation i (`<` becomes `<=`) is caught by that test.
