## Genuine finding and fix

`FrameParser` joined its whole buffer on every incoming chunk. A client that sends a large
allowed frame one byte at a time made the server do quadratic work: 6.9 s for 256 KiB, hours for
the 16 MiB default limit (a CPU denial of service). The coordinator reproduced it with a failing
test, then fixed it in `ad09784`: received bytes are kept as chunks and joined only when enough
have arrived for the next step, so each byte is copied a few times per frame. The same test now
runs in about 0.7 s. Mutation j (rejoin on every chunk) is caught by that test. ADR-0015 records
the resource bounds and the remaining limits (no connection cap, no idle timeout, no TLS).
