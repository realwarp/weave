## Window Boundary Analysis

From `packages/core/src/sync/ban.ts`:

```typescript
const recent = (this.strikes.get(peer) ?? []).filter((t) => now - t < this.settings.windowMs);
```

The window uses strict inequality `now - t < windowMs`, meaning:
- `t = N - W - 1`: excluded (time too old)
- `t = N - W`: excluded (exactly at boundary)
- `t = N - W + 1`: included (just inside window)

**Window boundary result**: N-W-1 **excluded**, N-W **excluded**, N-W+1 **included**

**Coverage finding**: The test `strikes older than the window do not count` covers:
- Strike at `now=0`, then `now=1000` (exactly at boundary, excluded)
- Strike at `now=1500` (500ms old, included, but not enough for ban)
- This confirms the boundary behavior
