## Verified

### Required behavior implemented and tested

1. **Semantic opacity (R4a.6)**: No imports of resolver, schema, migration modules (verified by `test/core/core.test.ts:154-171`)

2. **Full op verification (R16.1, R16.2)**: Every op line verified for structure, canonical form, D7 values, D2 hash recomputation (verified by `relay/src/core/index.ts:113-119`)

3. **Byte-for-byte storage (R4a.6)**: Ops stored and forwarded as received, canonical lines preserved (`relay/src/core/index.ts:201` stores `v.line`)

4. **Durable before acknowledge (R4a.3)**: Acknowledgement written only after transaction commit; crash after commit loses only response, not data (verified by `test/core/core.test.ts:123-147`)

5. **Single queue plus in-transaction recheck (R4a.7)**: Pushes serialized through `Queue` class (`relay/src/core/index.ts:79-88`), transaction re-checks identity for accepted ops (`relay/src/core/index.ts:233-238`)

6. **Contiguity and need (R4a.5)**: Contiguous prefix accepted per origin; gaps reported in `need` (`relay/src/core/index.ts:174-193`)

7. **Ack rules (R3.5, R4a.5, design 10.3)**: Ack rises only by `AckRequest` or validated pushed prefix, never by pull (verified by `test/ack/ack.test.ts`)

8. **Pull prefix rule with blocked origins (R4a.10)**: Prefix rule enforced using `selectReadablePrefix` (`relay/src/core/index.ts:102-108`)

9. **Limits (ops per push/pull, op bytes, body size)**: `maxOpsPerPush` (500), `maxOpsPerPull` (500), `maxOpBytes` (64 KiB), `maxBodyBytes` (4 MiB default) enforced with 413/400 responses (verified by `test/server/server.test.ts:58-68`)

10. **Bearer token constant-time compare (R4a.9)**: Uses `node:crypto.timingSafeEqual` (`relay/src/server/index.ts:55-59`)

11. **Token never logged (R4a.9)**: Log format `"{METHOD} /v1/{route} {status} {duration}ms"`; no secrets passed to log (`relay/src/server/index.ts:183-194`)

12. **Request validation (pull/push/ack bodies)**: Strict field-by-field validation (`relay/src/server/index.ts:64-106`)

13. **Binds 127.0.0.1 by default (R16.5)**: `listen()` default host `'127.0.0.1'`, `cli.ts` uses same default

14. **Graceful shutdown (SIGINT/SIGTERM)**: Signal handlers call `relay.close()` (`cli.ts:26-28`)

15. **Windows IPC 'shutdown' message (R16.5)**: `process.on('message')` handler for `'shutdown'` (`cli.ts:30-32`)

### Test coverage summary

- `test/ack/ack.test.ts`: 9 tests for ack rules (push only, gaps, rejected push, pull only, pull+ack, crash before ack, out-of-order/repeated acks, restart, unknown member)
- `test/core/core.test.ts`: 13 tests for push/pull, limits, concurrent pushes (queue + recheck), crash recovery, opacity, duplicates, gaps
- `test/server/server.test.ts`: 26 tests for HTTP server (health, token auth, body size limits, op limits, never log token/secrets)
- CLI smoke test: starts, responds to health, shuts down on SIGTERM

All 48 tests pass. Fuzz tests not present for relay; coverage is via conformance tests in `tests/relay/**`.

## Verdict

Verdict: PASS
