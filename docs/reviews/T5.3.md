## Check Brief Check 2

**Question**: Can a restore op reach accepted state on a collection without restore through pending-buffer sweep or newer schemaVersion op?

**Answer**: **NO**.

- **Pending-buffer sweep**: Sweep occurs in `applyOnce` phase A1 before A2 validation. In phase A2, every restore op triggers `assertRestoreAccepted(definition)` (line 602), which throws `NOT_SUPPORTED` for collections without `deletes.restore`. The batch is rejected.

- **Newer schemaVersion op**: Phase A2 skips ops with `op.schemaVersion > definition.version` (line 595). An older replica never reaches the restore validation for a newer schema.

**Code path**: `applyOnce` → Phase A2 loop → `assertRestoreAccepted` throws.
