## Boundary analysis

The spec (T5.7) leaves window boundary inclusivity undefined. ADR-0015 records the decision:

- **Decision**: A strike counts while it is less than `windowMs` old (`now - t < windowMs`).
- **N-W-1**: outside the window (counts false) - test passes
- **N-W**: exactly windowMs old (counts false) - test passes  
- **N-W+1**: inside the window (counts true) - test passes

Mutation i changed `<` to `<=` which made the boundary inclusive, causing the test `BanBook > window boundary: a strike counts while it is less than windowMs old (N-W-1, N-W, N-W+1)` to fail at `expect(counts(W)).toBe(false)`. This confirms the harness caught the boundary change.
