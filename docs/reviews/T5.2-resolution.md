# T5.2 findings and their resolution

The independent reviewer worked in a fresh worktree of commit `a09c660`, ran every gate and the
snapshot suites, and recorded **PASS** (`docs/reviews/T5.2.md`). Its three minor rows each state
that the behaviour is correct; they were checked against `packages/core/src/sync/snapshot.ts`.

| Finding | Disposition |
| ------- | ----------- |
| F1: the contiguity loop does nothing when `compactedThrough[o]` equals `vector[o]` | Correct: no op of that origin above the compacted point is promised, so none is required. No action. |
| F2: no check that op and archive counts match | Correct: archives are per record, not per op. No action. |
| F3: `coversCompacted` treats a missing origin as 0 | Correct: a snapshot without an origin covers nothing of it, so a relay that discarded that origin's history refuses it. No action. |

Known limit, recorded in ADR-0015: the snapshot's creator chooses its conflict-history archives.
The hash proves the snapshot was not altered after creation, not that a malicious member told the
truth; this is the same trust assumption as compaction (ADR-0006). Op lines and derived state are
verified and re-derived by the importer, so state cannot be forged this way.

No open findings. **T5.2 passes.**
